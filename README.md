# Hermes OS

Agentic Operating System — A unified framework for Hermes Agent ecosystem integration.

## Overview

Hermes OS is an agentic operating system layer built on top of the Hermes Agent (Nous Research). It integrates:

- **Web-based Dashboard UI** — Custom HTML/CSS/JS dashboard
- **Voice Dictation** — Glider speech-to-text integration
- **Multi-modal Chat** — Web chat + Telegram bridge
- **Knowledge Management** — Obsidian vault integration
- **Automation** — Zapier MCP server connector
- **Code Intelligence** — Code Graph dependency mapping
- **Git Backup** — Private GitHub mirror for config + personas
